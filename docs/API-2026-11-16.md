## Delivered

- `server/src/`: dependency-free Node.js HTTP API with a distinct bearer token, fixed board address, bounded network waits and private durable command history.
- `server/openapi.json`: API contract for status, On/Off requests and command-result lookup.
- `ios/LeafyClient.swift`: asynchronous URLSession client with redirect rejection, status decoding and explicit uncertain command outcomes. Store its token in iOS Keychain in the eventual app.
- `server/README.md`: configuration, launch, iPhone networking, response semantics and maintenance.
- Firmware `GET /api/v1/status`: authenticated JSON; legacy web routes still work.
- Firmware `telemetry.hpp`: OVMS-derived EV-CAN 0x55B SOC decoding with frame validation and age tracking.

Each heater intent has a UUID and a timestamp. The server persists the ID before delivery, rejects expired commands, avoids overlapping deliveries and never automatically retries a board command. Duplicate IDs return the original outcome, including after restart. The board's existing voltage checks, expiry, Off handling and local timer remain in force. Acceptance is explicitly distinct from confirmed heating.

The original installed firmware is supported for protected voltage and commands via its legacy status route. Battery percentage stays unavailable until updated firmware receives a valid frame. No zero or successful climate state is invented.

## Firmware behavior to validate physically

Idle telemetry uses listen-only CAN windows lasting 1.5 seconds every 60 seconds. It sends no wake, ACK or error frames during those windows. Commands preempt the passive listener and use the existing normal CAN transport. Received SOC is also collected during active command sequences.

The value is BMS SOC, not necessarily the dashboard percentage. Frames from a sleeping car may cease; samples older than 120 seconds are labelled stale, with their age. After reboot the value is null until a valid frame arrives. The added receive windows can affect parked current, so previous consumption observations do not qualify this new image.
